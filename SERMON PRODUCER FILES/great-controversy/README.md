# The Great Controversy — Learning Workspace

This is your personal study workspace for *The Great Controversy* by Ellen G. White.

## How to use

Tell Claude: **"teach me The Great Controversy"** (or any specific chapter, theme, or question).

Claude will ask you a few questions about your goals first, then begin building personalized lessons here.

## What gets created

| File / Folder | Purpose |
|---|---|
| `MISSION.md` | Your learning goal — why you're studying this and what success looks like |
| `RESOURCES.md` | Trusted sources: EGW writings, SDA scholarship, communities |
| `NOTES.md` | Your preferences and open questions |
| `lessons/` | Interactive HTML lessons — one concept each, completable in ~15 min |
| `reference/` | Printable cheat sheets: glossary, timeline, prophetic chart, key figures |
| `learning-records/` | What you've genuinely understood — used to plan what comes next |
| `assets/` | Shared stylesheet and quiz components used across all lessons |

## The Book at a Glance

- **Prologue** — Destruction of Jerusalem (70 AD)
- **Part I** (Ch. 1–16) — The Dark Ages: papal power, Wycliffe, Huss, Luther
- **Part II** (Ch. 17–28) — The Reformation: Luther, Calvin, the English church, Wesley
- **Part III** (Ch. 29–35) — The Advent Movement: the 2300-day prophecy, the Sabbath, the sanctuary
- **Part IV** (Ch. 36–42) — The Final Conflict: spiritualism, the mark, the time of trouble, the glorious appearing
