## Heading 2: Main Sections (H2)
Always start your primary sections with a Heading 2. This creates a proper HTML heading hierarchy since the main post title is automatically rendered as an `<h1>`.

Here is normal paragraph text. You can use **bold text**, *italics*, or `code blocks`.

### Heading 3: Subsections (H3)
If you need to break down a main section into smaller parts, use a Heading 3. Never skip levels (e.g., don't jump from an H2 straight to an H4).

## Scripture Callouts
For scripture quotes or other callout text, use the `div` with the class `scripture` and a `cite` tag for the reference:

<div class="scripture">
  "But now you must also rid yourselves of all such things."
  <cite>Colossians 3:8</cite>
</div>
